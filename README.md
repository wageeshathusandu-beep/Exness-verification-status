# Verification Status — Demo Dashboard

A clean, premium dark-UI document verification status dashboard. **This is an
independent demonstration and is not an official Exness service.**

## What it shows

- **Document Verification Status**
  1. Upload Documents — Completed ✅
  2. Document Processing — Completed ✅
  3. Verification Status — Pending 🟡
- A prominent yellow **Pending** badge.
- A professional **progress timeline** (horizontal on desktop, vertical on mobile).
- Prominent status message:

  > Your documents have been successfully submitted and are currently awaiting verification.

- Estimated processing time notice: **A few business days.**
- Reminder message:

  > Please wait while our verification team reviews your submitted documents.

## Features

- Single self-contained `index.html` (no build step, no external dependencies).
- Premium dark theme with glassmorphism cards and subtle glow accents.
- Fully responsive: timeline collapses to a vertical layout on mobile.
- Accessible: semantic landmarks, `aria-live` status region, reduced-motion support.

## Usage

Just open `index.html` in any modern browser. No server required.
